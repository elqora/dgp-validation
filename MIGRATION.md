# Validation migration evidence

DGP Validation is the complete publication validator for canonical v1 definitions. Universal rules run by default. Catalog, rate-policy, fallback-policy, field-registry, and host-policy checks run only when their required external evidence is supplied. No rule calculates a final price or charge.

Legacy aliases, `flags`, `estimates`, component identifiers, derived authored fields, UI presentation, and customer-facing editorial diagnostics are excluded as representations or other package concerns under the approved v1 clean break. Their accepted validation outcomes are represented by canonical contracts, registry/catalog inputs, or optional host policies.
