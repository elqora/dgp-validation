# Validation migration evidence

DGP Validation is the publication-validation destination for canonical v1 definitions. This ledger records evidence, not aspirations. `Verified` means the named legacy outcomes have direct canonical replacement tests. `In progress` means implementation exists but the applicable legacy matrix is not yet fully mapped and replaced. No row may be promoted merely because the repository-wide checks pass.

Universal rules run by default. Catalog, rate-policy, fallback-policy, field-registry, and host-policy checks run only when their external evidence is supplied. Validation never calculates a final price or charge.
