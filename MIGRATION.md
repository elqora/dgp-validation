# Validation migration evidence

DGP Validation is the full-scale publication validator for canonical v1 definitions. Universal rules run by default; checks requiring a service catalog, rate policy, field registry, or host policy remain reusable configurable validators or policy packs. Backend pricing authority does not remove publication-time coherence validation.
